# Summary

A `JOSS` module evaluates the items in the [JOSS review checklist](https://joss.readthedocs.io/en/latest/review_checklist.html) that can be checked automatically. It is registered through the `JOSSPlugin` entry point and contributes 16 requirements across two queries.

# Motivation

Authors preparing a Journal of Open Source Software submission, and reviewers assessing one, manually verify many checklist items that are mechanically determinable from GitHub metadata and repository contents. Automating these items surfaces gaps before submission and reduces review effort.

# Changes

- `joss_plugin.py` and `joss_impl/module.py` define `JOSSModule`, built on the shared `RepositoryModule`.
- `GitHubQuery` retrieves repository metadata, the first commit date, and non-bot contributors, and evaluates:
  - `LicenseRequirement`: GitHub detects an OSI-approved license.
  - `PublicHistoryRequirement`: the repository is public and has existed for a minimum number of months.
  - `DevelopmentHistoryRequirement`: the first commit was authored at least 6 months ago.
  - `ContributorsRequirement`: commits from at least 2 people.
  - `IssuesRequirement`: issues are enabled.
- `RepositoryQuery` clones the repository, locates the README and `paper.md` (`documents.py`), and evaluates:
  - README headings for statement of need, installation, and example usage (`ReadmeHeadingRequirement`).
  - Presence of documentation, test, and `CONTRIBUTING` files or directories.
  - `paper.md` existence, YAML front-matter metadata, required sections, length (750-1750 words), and references.
- `pyyaml` added as a dependency to parse paper front matter.
- README lists the module and the PAT permissions it requires (`Contents: Read`, `Metadata: Read`).
- Tests cover each requirement, both queries, document parsing, and plugin registration; entry point tests account for the fourth module.

# Compatibility

The module requires explicit inclusion via `--JOSS-include`, so existing audits are unaffected. Module execution order is now GitHub, CommunityStandards, JOSS, ScientificSoftware.
